# SITE_MAP

> 사용자가 설명한 iOS 모의면접 화면·기능의 요구사항이다. 실제 화면 분리, 표시 명칭, 배치, 탐색 구조와 로그인 사용 여부는 미정이다. 이 문서의 기능 명칭은 최종 일본어 UI 문구가 아니다.

## 1. 화면·기능 목록
| 화면·기능 | 확정된 요구사항 |
|---|---|
| 설정 등의 메뉴 | 질문 개수의 첫 사용 기본값은 5문이며, 3~7문으로 조절한다. |
| 모의면접 시작 | 회사명, 업종, 직무, 인사/직무 면접을 선택한다. |
| 준비 화면 | 시선·머리 움직임을 정확히 관찰할 수 있는 거리인지 확인한다. 전면 카메라 동작과 TrueDepth 지원 여부를 확인한다. |
| 면접 진행 | AI 질문의 음성 재생, 사용자 답변의 실시간 문자 표시, 무음에 따른 자동 답변 완료, 설정된 질문 개수만큼 반복한다. |
| 결과 확인 | 종합평가 점수, 각 항목별 점수, 질문·답변 스크립트를 표시한다. |
| 과거 모의면접 확인 | 휴대폰 내부에 저장된 과거 질문·답변 스크립트를 다시 볼 수 있다. 기록을 한 건씩 선택해 확인 후 삭제할 수 있다. |

### 1.1 질문 개수 기본값 승인 (2026-11-05)
사용자가 앱 첫 사용 시 질문 개수 기본값을 5문으로 두는 방식을 승인했다. 사용자는 설정 등의 메뉴에서 3~7문으로 변경할 수 있다. 설정 화면의 위치·조작 방식과 설정값 저장 방식은 미정이다. 설정 기능 구현이나 앱 시험은 수행하지 않았다.

## 2. 화면 간 흐름
1. 회사명·업종·직무·면접 종류 선택 → 준비 화면 진입
2. 거리 및 카메라/TrueDepth 지원 확인 → 모의면접 진행
3. AI가 TTS(문자를 음성으로 읽는 기능)로 질문 → 질문이 끝나면 사용자 답변 차례
4. 사용자 답변을 STT(음성을 문자로 바꾸는 기능)로 화면에 표시 → 일정 시간 무음이면 답변 완료
5. 다음 질문으로 이동하며 설정한 3~7문까지 반복 → 면접 종료
6. 답변 평가 완료 → 종합점수·항목별 점수·질문 및 답변 스크립트 확인

과거 기록에 진입하는 탐색 경로와 설정 메뉴 위치는 미정이다.

## 3. 준비 화면과 평가 제외 조건
- 시선과 머리 움직임을 정확히 관찰할 수 있는 거리인지 확인한다. 거리 기준과 안내 방식은 미정이다.
- 전면 카메라가 정상적으로 동작하지 않거나 기기가 TrueDepth를 지원하지 않으면 시선·머리 움직임을 모두 채점 항목과 종합점수에서 제외한다.
- 제외 항목은 0점으로 반영하지 않는다. 제외 상태를 결과 화면에서 어떻게 표시할지는 미정이다.
- 카메라·마이크 권한 거부, 면접 도중 관찰 실패 등 추가 상황의 처리는 별도로 논의한다.

## 4. 면접 진행과 결과 확인
- 질문을 읽는 동안과 사용자가 답변하는 차례를 구분한다.
- 답변 중에는 사용자의 말을 문자로 표시한다.
- 사용자가 일정 시간 말하지 않으면 다음 질문으로 진행한다. 무음 판정 시간은 미정이다.
- 면접 중 시선·머리 움직임을 실시간 관찰한다. 지원되지 않는 경우에는 두 항목을 제외한다.
- 종료 후 답변의 구성·논리력·현실성을 평가하고, 종합평가 점수·각 항목별 점수와 질문·답변 스크립트를 표시한다.
- 일시정지, 중도 종료, 답변 수정·재시도 등은 아직 정하지 않았다.

### 4.1 답변 중 무음 시간 검토 (제안, 미승인)
사용자가 답변을 시작한 뒤 마지막 발화가 끝난 시점부터 7초간 연속으로 말하지 않으면 답변 완료로 판단하는 안을 제안한다. 짧게 생각하는 멈춤을 허용하면서 자동으로 다음 질문에 진행하기 위한 초기 제안이며, 실제 면접에서 적절한지는 아직 검증하지 않았다.

7초 기준은 아직 승인받지 않았다. 이 제안은 답변이 시작된 뒤의 무음에 대한 것이며, 질문 재생 후 첫마디를 시작하기 전의 대기시간과 미응답 처리는 별도 미정이다. 발화·무음 검출 방법과 인식 오류 처리는 아직 정하지 않았다.

## 5. 과거 기록
- 휴대폰 내부에 질문·답변 스크립트와 면접 시작 일시·회사명·업종·직무·면접 종류(인사/직무)를 함께 저장한다.
- 사용자는 과거 모의면접의 스크립트를 다시 확인할 수 있다.
- 기본정보는 기록 구분과 당시 연습 조건 확인을 위해 보관한다. 과거 기록은 면접 시작 일시를 기준으로 최신 기록을 위에 표시한다. 목록 구성과 날짜·시간의 표시 형식은 미정이다.
- 사용자가 기록을 한 건씩 선택해 삭제할 수 있다. 삭제 전 확인 창을 표시하고, 삭제를 확인하면 해당 기록의 스크립트와 기본정보를 함께 삭제하며 취소하면 유지한다. 승인 범위는 [DATA.md](../system-design/DATA.md)의 1.4를 따른다. 삭제 버튼 위치·조작 방식·최종 일본어 문구는 미정이다.

### 5.1 과거 기록 표시 순서 승인 (2026-11-05)
사용자가 면접 시작 일시를 기준으로 최신 기록을 위에 표시하는 방식을 승인했다. 최근 연습을 쉽게 다시 확인하기 위한 순서다. 같은 시작 일시를 가진 기록의 순서, 목록 구성과 날짜·시간 표시 형식은 미정이다. 화면 구현이나 실제 정렬 시험은 수행하지 않았다.

## 6. 공통 레이아웃·네비게이션
- 레이아웃, 화면별 최종 명칭, 전역 탐색 구조는 미정이다.
- 서비스 화면 문구는 일본어로 작성한다.
- 취업활동 관리 기능의 화면과 흐름은 아직 논의하지 않았다.
