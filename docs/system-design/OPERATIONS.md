### 1.1 사용자가 보유한 테스트 기기 (2026-11-05)
| 기기 | 칩 | TrueDepth 카메라 | Apple Intelligence | 실제 설치된 iOS |
|---|---|---|---|---|
| [iPhone 14 Plus](https://support.apple.com/en-sg/111854) | A15 Bionic | 탑재 | 미지원 | 미확인 |
| [iPhone XR](https://support.apple.com/en-la/111868) | A12 Bionic | 탑재 | 미지원 | 미확인 |

- 두 기기를 보유하고 있다는 사용자 확인을 기록했다. 출시 지원 목표는 가능하다면 iPhone 13 이상이고, 최소 OS는 iOS 26.0이다. 하드웨어 지원 가능 여부는 검증이 필요하며, 보유 기기 목록을 출시 지원 범위로 간주하지 않는다.
- 칩·카메라 탑재 여부는 Apple 공식 사양, Apple Intelligence 지원 여부는 [공식 지원 조건](https://support.apple.com/en-gb/121115)으로 확인했다. 실제 카메라 동작·권한 상태·추적 품질은 아직 시험하지 않았다.
- XR은 [iOS 26 호환 기기 목록](https://support.apple.com/en-ie/guide/iphone/-iphe3fa5df43/ios)에 포함되지 않아 승인된 OS 하한으로 구성할 앱의 설치 대상이 아니다. 보유 기기 정보는 유지한다.
- 모델 다운로드·설치 및 실제 기기에서의 LLM·음성·시선/머리 움직임 시험은 아직 수행하지 않았다.

### 1.2 출시 지원 목표와 검증 범위 (2026-11-05)
- 사용자 희망: 가능하다면 iPhone 13 이상을 정식 출시 때 지원한다. 성능 검증 없이 지원을 확정하지 않는다.
- 현재 iPhone 13 실기기는 보유 테스트 기기에 포함되지 않는다. 14 Plus 또는 XR의 측정 결과만으로 iPhone 13에서의 동작·성능을 검증했다고 보고하지 않는다.
- [iPhone 13](https://support.apple.com/en-ie/111872)은 A15 Bionic·4코어 GPU, [14 Plus](https://support.apple.com/en-sg/111854)는 A15 Bionic·5코어 GPU다. 같은 칩 이름만으로 동일한 실행 성능을 가정하지 않는다.
- iPhone 13 이상이라는 조건부 하드웨어 지원 목표와 별도로, 앱이 요구할 최소 iOS 버전은 26.0으로 승인받았다. 시험 순서·합격 기준은 미정이다. 첫 검증 모델은 LFM2.5-1.2B-JP-202606, 검증용 실행 도구는 MLX Swift LM으로 사용자 승인을 받았으며, 제품 최종 모델은 미정이다.

### 1.3 첫 검증 모델 선정 승인 (2026-11-05)
- 첫 검증 모델: `LFM2.5-1.2B-JP-202606`.
- 확인할 항목: 일본어 면접 평가 품질, 응답 시간, 메모리 사용량, 발열. 합격 기준과 검증용 질문·답변 자료는 아직 정하지 않았다.
- 검증용 실행 도구는 이후 MLX Swift LM, 최소 iOS 버전은 26.0으로 승인받았다. 모델 파일의 압축 형식, 실행 도구의 버전·연동 설정과 검증 앱 구성은 미정이다.
- Mac에서 Xcode 개발 도구 경로와 Swift 실행 파일의 존재를 읽기 전용으로 확인했다. 현재 확인한 버전은 1.4를 따른다. 빌드, 모델 다운로드·설치, 실제 기기 시험은 수행하지 않았다.
- 자세한 승인 범위와 실행 도구 선정 기록은 [ARCHITECTURE.md](ARCHITECTURE.md)를 따른다.

### 1.4 검증용 실행 도구 선정 승인 (2026-11-05)
- 사용자가 MLX Swift LM을 검증용 모델 실행 도구로 승인했다. 패키지 설치·버전 고정·연동 설정·앱 구현은 아직 수행하지 않았다.
- 로컬 개발 도구를 읽기 전용으로 확인한 결과 Xcode 27.2, Build version 27B52다. 보유 iPhone에 실제 설치된 iOS 버전은 미확인이다.
- 최소 iOS 버전은 이후 26.0으로 승인받았다. 비교 근거와 후속 음성 인식 제안은 [ARCHITECTURE.md](ARCHITECTURE.md)의 6.9·6.10을 따른다.

### 1.5 최소 iOS 버전 승인 (2026-11-05)
- 사용자가 최소 iOS 버전을 26 이상으로 승인했다. 향후 프로젝트의 설치 하한은 iOS 26.0으로 구성한다.
- iPhone 14 Plus에 설치된 OS가 26 이상인지 확인해야 한다. XR은 이 하한을 충족할 수 없다.
- 문서에 요구사항을 반영했으며, 아직 생성되지 않은 앱의 빌드 설정을 변경한 것은 아니다.
- 음성 인식 도구는 이후 SpeechAnalyzer + SpeechTranscriber로 승인받았다. 지원되지 않을 때의 처리와 언어 모델 다운로드 시점·안내 방식은 미정이다.

### 1.6 음성 인식 도구 승인 (2026-11-05)
- 사용자가 기기 내부 STT 도구로 SpeechAnalyzer + SpeechTranscriber를 승인했다.
- 기기 지원 여부와 일본어 지원·설치 상태, 인식 품질·지연 시간을 실기기에서 검증해야 한다. 실제 검증은 아직 수행하지 않았다.
- 필요한 경우 언어 모델 다운로드·설치를 진행할 시점과 안내 방식, 지원되지 않거나 인식에 실패했을 때의 처리, 무음 판정 시간은 미정이다.
- 음성 인식 기능 구현·언어 모델 설치·외부 음성 인식 서비스 도입은 수행하지 않았다. TTS 도구는 이후 AVSpeechSynthesizer로 승인받았다.

### 1.7 질문 음성 출력 도구 승인 (2026-11-05)
- 사용자가 TTS 도구로 AVSpeechSynthesizer를 승인했다.
- 사용할 일본어 목소리·품질·읽기 속도·음높이, 필요한 음성의 다운로드 안내 방식은 미정이다.
- 실기기에서 음성의 설치 상태, 회사명·직무 용어의 발음, 재생 완료 후 답변 차례 전환과 오프라인 재생을 확인해야 한다. 실제 검증은 아직 수행하지 않았다.
- 음성 출력 기능 구현·음성 설치·재생 시험은 수행하지 않았다. 시선·머리 움직임 관찰 기술은 이후 ARKit으로 승인받았다.

### 1.8 시선·머리 움직임 관찰 기술 승인 (2026-11-05)
- 사용자가 시선·머리 움직임 관찰 기술로 ARKit을 승인했다.
- TrueDepth 지원·전면 카메라 정상 동작을 확인하며, 조건을 충족하지 않으면 두 움직임 항목을 모두 채점 및 종합점수에서 제외한다.
- 기기 지원 여부, 시선 추정 정확도, 준비 화면의 적정 거리, 보정 방법, 관찰 도중 추적 실패 시 처리는 확인·논의가 필요하다. 움직임 지표와 채점 기준은 미정이다.
- ARKit 연동·카메라 시험·거리 보정·실제 기기 추적 시험은 수행하지 않았다. 앱 개발 언어·화면 도구는 이후 Swift·SwiftUI로 승인받았다.

### 1.9 앱 개발 언어·화면 도구 승인 (2026-11-05)
- 사용자가 개발 언어 Swift와 화면 도구 SwiftUI를 승인했다. 언어 버전, 프로젝트 구조, 앱 생성·구현 범위는 아직 정하지 않았다.
- 테스트 구성은 이후 1.10과 같이 승인받았다. 앱 프로젝트나 화면 코드는 아직 생성하지 않았다.

### 1.10 테스트 구성 승인 (2026-11-05)
- 사용자가 단위·통합 테스트에 Swift Testing, UI 자동화에 XCTest + XCUIAutomation, 성능 측정에 XCTest를 사용하는 구성을 승인했다. 역할과 예시는 [ARCHITECTURE.md](ARCHITECTURE.md)의 6.14를 따른다.
- 일본어 음성·시선 추정·LLM 평가 품질과 전체 면접 중 발열은 실기기에서 별도로 확인해야 한다.
- 구체적인 테스트 대상·구조·실행 명령·성능 합격 기준은 미정이다. 테스트 파일 생성·시험 실행·앱 구현은 수행하지 않았다.
