# 임시 면접 핵심 소스 구현 계획

> 2026-11-05 사용자가 `ios_temp/`에 나중에 iOS 프로젝트로 옮길 Swift 소스 작성을 요청했다. 앞선 별도 제품 패키지 생성안은 사용하지 않는다. 기존 승인된 계산·진행 규칙과 그 독립 시험을 구현하며 실제 화면·저장·AI·음성·추적의 미정 사항은 결정하지 않는다.

## 1. 경로와 인계 범위

- 사용자 예정 작업: 저장소 루트 `FirstStepToCareer/`에 Xcode 프로젝트 생성 → 바깥 폴더명을 `ios/`로 변경.
- 에이전트 작업: `ios_temp/Sources/Core/`에 앱 대상으로 옮길 소스, `ios_temp/Tests/Core/`에 단위 시험 대상으로 옮길 Swift Testing 시험 작성.
- 프로젝트·앱 시작점·화면·서명·앱 식별자는 생성하지 않는다. 앱 모듈 이름이 `FirstStepToCareer`와 다르면 시험의 import만 맞춘다.
- 검증용 패키지는 스크립트 실행 시 임시 경로에만 만든다. 제품 패키지·외부 의존성을 추가하지 않는다.
- 상세 이전 순서는 [INTEGRATION.md](../../ios_temp/INTEGRATION.md)를 따른다.

## 2. 작업·커밋 단위

각 행에 해당 구현·시험·TASK.md 상태와 관련 문서를 함께 넣는다. 검증 성공 후 커밋하고 즉시 푸시하며 성공을 확인한 뒤 다음 단위를 진행한다.

| 순서 | 범위 | 주요 파일 | 상태 |
|---|---|---|---|
| 1 | 임시 소스 구조, 질문 기본값 5·허용 범위 3~7, 검증 도구·이전 안내 | `InterviewConfiguration.swift`, 대응 시험, `Scripts/verify.sh`, `INTEGRATION.md` | 작성·질문 설정 시험 완료 |
| 2 | 세부 기준 0/1/2점 환산·완료 문항 평균, 비중 25/30/25/10/10과 제외 환산, 완료 비율·추가 5점 감점, 표시 한 자리 반올림 | `Score.swift`, `AnswerScoring.swift`, `OverallScoring.swift`, 대응 시험 | 진행 예정 |
| 3 | 중앙 50/70/90% 사각 구간·안쪽 경계 포함, 단계별 감점·하한 0, 짧은 누락 건너뛰기·연속 3초 누락 시 두 항목 전체 제외 | `MovementScoring.swift`, 대응 시험 | 진행 예정 |
| 4 | 새 단어 시작·3초 무음 완료·7초 무응답 재질문/종료, 질문/평가 중 이어 말하기와 취소, 문항 번호·완료 수·답변 보존, 전 구간 움직임 적용 | `InterviewSession.swift`, 대응 시험 | 진행 예정 |

Swift 소스 파일은 모두 `ios_temp/Sources/Core/`, 대응 시험은 `ios_temp/Tests/Core/`에 둔다. 선행 추적 불가 3초 승인 기록을 보존한다.

## 3. 구현 방식과 검증

- Swift 6 언어 모드에서 검증한다. 점수는 정수 분자·분모로 표현하고 표시할 때만 반올림한다. 문항 수·배점·감점 단위는 정수로 관리한다.
- 움직임의 시험 위치는 화면 폭·높이를 각각 0~1로 나타낸 값이다. 실제 ARKit 좌표의 화면 변환을 뜻하지 않는다.
- 면접 코드는 사건을 전달받아 진행 단계와 필요한 작업 지시를 만든다. 새 단어 감지·무음 시작·STT 시작·작업 완료·시간 진행을 시험에서 전달한다. 실제 일본어 단어 판별·무음 검출은 구현하지 않는다.
- 이어 말하기로 취소한 작업은 식별 값을 바꾸어 늦게 도착한 이전 결과를 반영하지 않도록 한다. 실제 AI·음성 작업 취소는 후속 연결 대상이다.
- 실제 질문 생성·답변 평가는 연결하지 않는다. 시험에서 세부 점수를 입력하며, 계산 시험 성공을 AI 평가 품질 검증으로 보고하지 않는다.
- 최종 질문과 기존·추가 발화의 순서는 메모리에서 보존한다. 문자열을 공백·줄바꿈으로 어떻게 합칠지와 SwiftData 저장 구조·시점은 결정하지 않는다.
- 경계값과 실패 사례: 질문 수 2/3/5/7/8, 완료 문항 0개·중복 집계 방지, 무응답 7초·답변 종료 3초의 직전/도달/직후, 화면 구간의 선·모서리·바로 안팎, 누적 감점 하한, 취소된 결과의 늦은 도착.
- 승인 계산 예시: 다섯 항목 78.5점, 움직임 제외 80.625점→80.6, 5문 중 3문 완료·품질 80점일 때 48점/이어 말하기 실패 43점, 정수 80→80.0, 82.35→82.4.
- 동시 사건의 우선순위·카운트다운 중 이어 말하기·결과 표시 후 재개·관찰 자료가 전혀 없는 경우는 제품 동작으로 확정하지 않는다. 필요한 경우 승인 경계로 표시한다.

## 4. 검증 환경과 한계

Xcode 27.2(27B52), Swift 6.4.2, SDK 27.2 환경에서 `bash ios_temp/Scripts/verify.sh`로 iOS 26 배포 대상 소스 검사와 Mac 단위 시험을 수행한다. 임시 패키지의 Mac 대상은 개발용 시험만을 위한 것이며 앱 출시 플랫폼은 iOS만 유지한다. 실제 iOS 앱 링크·설치·실행·UI·성능 시험은 사용자 프로젝트 생성 후 수행한다.

## 5. 별도 승인 대상으로 남기는 사항

- 화면 분리·탐색·배치·일본어 문구·타이머 모양·제외 안내와 복수 사유 표시.
- SwiftData 엔티티·필드·관계·식별자, 저장 시점·조기 종료 이력·보관/백업/복구·같은 시작 일시 정렬.
- MLX Swift LM 버전·연동 설정, 모델 파일·배포/다운로드, 질문·평가 지시문·출력 형식·오류 처리·품질과 성능 합격 기준, 제품 최종 모델·서버·외부 전송 여부.
- STT 단어·중간/확정 결과 반영·무음 검출·권한/오류·언어 모델 설치, TTS 목소리·속도·오디오 제어.
- 실제 시선·머리 기준점·좌표 변환·보정·거리·정상 자료 품질·누락/회복 감지·시간 측정·관찰 시각·제외 후 카메라 운용. 승인된 추적 제외 규칙은 합성 입력으로만 시험한다.
- 설정 저장·변경 적용 시점·비활성 상태 카메라 동작, 동시 사건 우선순위, 완료 0개일 때 항목 표시, 일시정지·사용자 중도 종료·취업활동 관리 범위.

점수·음성·영상·움직임 원본·제외 사유를 과거 이력에 저장하는 기능을 추가하지 않는다. 보유 iPhone 14 Plus의 OS·연결 상태와 iPhone 13 지원·성능은 별도 실기기 검증 대상이다.
