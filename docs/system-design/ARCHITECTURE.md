## 1. 개요
<!-- 이 시스템이 무엇을 하는지 2~3줄. 어디까지가 이 저장소의 책임이고 무엇이 바깥(외부 API, 기존 서비스)인지. -->
就活一歩는 혼자서 면접을 연습하고 취업활동을 관리하기 위한 iOS 전용 앱이다.
화면 언어는 일본어이며 일본에만 출시할 예정이다. 서버는 가능하면 사용하지 않되, 사용 여부는 미정이다.
기술 스택, 최소 iOS 버전, 데이터 저장 방식은 사용자 승인 후 결정한다.
정식 출시 때는 가능하다면 iPhone 13 이상을 지원하는 것이 사용자 목표다. 실제 지원 범위는 기기·성능 검증 후 결정한다.

### 1.1 모의면접 구성
- 사용자는 회사명, 업종(예: 금융·IT·보육), 직무(예: 상담원·테스터), 면접 종류(인사/직무)를 선택하고 모의면접을 시작한다.
- 질문 개수는 설정 등의 메뉴에서 3~7문으로 조절한다. 기본값과 설정 화면의 구체적인 배치는 미정이다.
- 인사면접은 성격, 가치관, 협업, 지원 동기를 평가한다.
- 직무 면접은 선택한 직무에 대한 실무 지식, 문제 해결 능력, 직무 전문성 등을 평가한다.
- AI가 정해진 질문을 진행한다. 질문을 어떻게 구성·선정할지와 AI 처리 위치는 미정이다.

### 1.2 평가 항목과 시점
| 평가 항목 | 관찰·평가 시점 | 적용 조건 |
|---|---|---|
| 답변의 구성 | 면접 종료 후 | 기본 평가 항목 |
| 답변의 논리력 | 면접 종료 후 | 기본 평가 항목 |
| 답변의 현실성 | 면접 종료 후 | 기본 평가 항목 |
| 시선의 움직임 | 면접 중 실시간 관찰 | 전면 카메라 정상 동작 및 TrueDepth 지원 시 |
| 머리의 움직임 | 면접 중 실시간 관찰 | 전면 카메라 정상 동작 및 TrueDepth 지원 시 |

- 정해진 계산식으로 각 항목과 종합평가 점수를 산출한다. 계산식, 배점, 가중치, 점수 범위는 미정이다.
- 전면 카메라가 정상적으로 동작하지 않거나 TrueDepth를 지원하지 않는 기기에서는 시선·머리 움직임을 모두 채점 항목과 종합점수 계산에서 제외한다. 해당 항목을 0점으로 처리하지 않는다.
- 인사/직무 면접별 평가 관점을 위 공통 채점 항목에 어떻게 반영할지는 미정이다.

### 6.1 모의면접 시작부터 결과 확인까지
1. 사용자가 회사명·업종·직무·면접 종류를 선택한다. 질문 개수는 설정 등의 메뉴에서 지정한 3~7문을 사용한다.
2. 준비 화면에서 시선·머리 움직임을 정확하게 관찰할 수 있는 거리인지 확인한다.
3. 전면 카메라 동작과 TrueDepth 지원 여부를 확인한다. 둘 중 하나라도 충족하지 않으면 시선·머리 움직임을 채점 및 종합점수 계산에서 제외한다.
4. AI가 질문을 TTS(문자를 음성으로 읽는 기능)로 읽는다.
5. 질문이 끝나면 사용자 차례가 된다. STT(음성을 문자로 바꾸는 기능)로 사용자의 말을 화면에 표시한다.
6. 사용자가 일정 시간 이상 말하지 않으면 답변이 끝난 것으로 간주한다. 무음 판정 시간은 미정이다.
7. 설정한 질문 개수만큼 질문과 답변을 반복한다. 시선·머리 움직임 평가가 가능한 경우 면접 중 실시간으로 관찰한다.
8. 면접 종료 후 답변의 구성·논리력·현실성을 평가하고, 종합평가 점수·각 항목별 점수·질문 및 답변 스크립트를 표시한다.

### 6.2 과거 모의면접 확인
1. 과거 모의면접은 질문 및 답변 스크립트만 휴대폰 내부에 저장한다.
2. 사용자는 저장된 과거 모의면접 스크립트를 다시 확인할 수 있다.

### 6.3 논의가 필요한 사항
- AI의 질문 구성·선정 및 답변 평가 방식, 기기 내부/외부 처리 여부, 서버 사용 여부
- 채점 계산식·점수 범위·가중치 및 시선·머리 움직임 제외 시 종합점수 산출 방식
- 질문 개수의 기본값 및 답변 완료로 판단할 무음 시간
- 적정 거리 기준, 관찰 품질 기준, 권한 거부 및 면접 도중 관찰 실패 시 처리
- 스크립트 저장 형식과 과거 기록을 구분하기 위한 정보의 범위
- 취업활동 관리 기능의 구체적인 범위

### 6.4 기기 내부 일본어 LLM 가능성 조사 (2026-11-05)
사용자는 가능하면 매우 가벼운 일본어 LLM을 휴대폰 내부에서 실행하기를 원한다. 첫 검증 모델은 이후 LFM2.5-1.2B-JP-202606으로 승인받았다(6.7 참조). 제품 최종 모델, 실행 도구, 최소 지원 기기, 서버 사용 여부는 확정하지 않았다. 외부 전송 허용 여부도 여전히 미정이다.

기기 내부에서 LLM을 실행하는 선택지는 존재한다. 아래 내용은 공식 자료 조사 결과이며, 실제 iPhone에서 이 앱의 성능·채점 품질을 검증한 결과는 아니다.

| 검토 후보 | 공식 자료에서 확인한 내용 | 이 앱에서 추가로 확인할 사항 |
|---|---|---|
| [LFM2.5-1.2B-JP-202606](https://huggingface.co/LiquidAI/LFM2.5-1.2B-JP-202606) | 약 11.7억 매개변수의 일·영 텍스트 모델. 기기 내부 비서와 구조화 출력 등이 권장 용도이며, 지식 집약적 작업은 비권장 | 일본어 면접 답변의 구성·논리력·현실성 및 직무 지식 판단 품질 |
| [Apple Foundation Models의 기기 내부 모델](https://developer.apple.com/foundation-models-framework/) | Apple Intelligence의 기기 내부 모델을 앱에서 사용해 인터넷 없이 처리 가능. 현재 프레임워크에는 클라우드 모델도 있으므로 기기 내부 모델을 명시적으로 구분해야 함 | [지원 기기·언어 조건](https://support.apple.com/en-gb/121115) 및 [실행 시 모델·언어 가용성](https://developer.apple.com/documentation/foundationmodels/supporting-languages-and-locales-with-foundation-models), 일본어 면접 평가 품질 |
| [Qwen3.5-0.8B](https://huggingface.co/Qwen/Qwen3.5-0.8B) / [2B](https://huggingface.co/Qwen/Qwen3.5-2B) | 8억/20억 매개변수 규모의 공개 모델. [공식 언어 목록](https://qwen.ai/blog?id=qwen3.5)에 일본어 포함. 0.8B는 제작사가 시제품·작업별 미세조정·연구개발 용도를 명시 | 작은 크기만으로 일본어 면접 채점 품질을 보장할 수 없으며, 실행 도구와 iPhone 성능 검증 필요 |

용량은 실행 시 메모리 사용량과 구분한다. Liquid AI가 공개한 LFM2.5-1.2B-JP-202606의 [MLX 4비트 가중치 파일은 692 MB](https://huggingface.co/LiquidAI/LFM2.5-1.2B-JP-202606-MLX-4bit/tree/main), [GGUF Q4_K_M 파일은 731 MB](https://huggingface.co/LiquidAI/LFM2.5-1.2B-JP-202606-GGUF/tree/main)이다. 4비트 양자화는 모델의 수치 표현을 줄여 용량을 낮춘 형식이다. 실행에는 대화 내용과 작업 공간 등을 위한 추가 메모리가 필요하므로 파일 크기를 필요 RAM으로 간주하지 않는다. 모델을 다운로드하거나 설치하지 않았다.

조사에 따른 제안과 후속 상태(첫 검증 모델 선정 외 제안은 미승인):
- 첫 검증 모델 선정은 6.7에서 승인받았다. Apple 모델 또는 Qwen을 추가 비교할지와 제품 최종 모델은 미정이다.
- LLM에 근거와 평가 항목을 추출하게 하고, 확정된 계산식의 합산은 앱 코드에서 처리하는 방식을 검토한다. 이 경우에도 LLM의 항목별 판단이 일관적인지는 따로 검증해야 한다.
- 상세 직무 지식을 모델 자체의 기억에만 의존하지 않도록, 직무별 기준 답안·채점 기준을 함께 제공하는 방식을 검토한다.
- 실제 iPhone에서 일본어 답변의 품질과 채점 일관성, 대기 시간, 메모리, 발열을 확인한다. 3문·7문과 카메라 관찰·음성 처리까지 포함한 전체 흐름 검증이 필요하다.
- LLM을 기기 내부에서 실행하더라도 TTS·STT의 처리 위치와 초기 모델 배포/다운로드 방식은 별도 검토가 필요하다. 완전한 오프라인 동작과 서버 미사용을 아직 확정하지 않는다.

### 6.5 보유 테스트 기기에 따른 검토 조건 (2026-11-05)
- 사용자는 iPhone 14 Plus와 iPhone XR을 테스트에 사용할 수 있다. 사양과 설치된 OS 확인 상태는 [OPERATIONS.md](OPERATIONS.md)의 테스트 기기 표를 따른다. 이후 사용자가 정한 출시 지원 목표는 가능하다면 iPhone 13 이상이며, 보유 기기 목록과 출시 지원 범위를 구분한다.
- 두 기기는 [Apple Intelligence 지원 대상](https://support.apple.com/en-gb/121115)이 아니므로 Apple의 기기 내장 모델을 직접 시험할 수 없다. 별도 경량 모델을 앱에서 실행하는 방식은 계속 검토할 수 있으며, 보유 기기에서의 호환성·성능을 보장하는 것은 아니다.
- 현재 [MLX Swift](https://github.com/ml-explore/mlx-swift/blob/main/Package.swift)와 [MLX Swift LM](https://github.com/ml-explore/mlx-swift-lm/blob/main/Package.swift)의 패키지에는 iOS 17이 최소 OS로 선언되어 있다. 이는 특정 모델의 XR 실행 보장이 아니며, Foundation Models 연동 등 일부 기능에는 더 높은 OS 조건이 있다. 실행 도구·버전·기기 호환성은 별도 검증 후 사용자 승인을 받아야 한다.
- 제안(미승인): 14 Plus에서 일본어 경량 모델의 응답 품질·대기 시간·메모리·발열을 먼저 확인하고, XR에서는 실행 가능 여부와 전체 면접 흐름을 별도로 검증한다. 테스트 순서 제안이며 최소 지원 기기를 정한 것이 아니다.
- 출시 지원 목표는 가능하다면 iPhone 13 이상으로 기록한다. 첫 검증 모델은 LFM2.5-1.2B-JP-202606으로 승인받았으며, 제품 최종 모델, 최소 iOS 버전, 실행 도구와 서버 사용 여부는 계속 미정이다.

### 6.6 iPhone 13 이상 출시 지원 목표 (2026-11-05)
- 사용자는 가능하다면 iPhone 13 이상을 지원하고 싶다고 밝혔다. 이는 조건부 목표이며 검증을 마친 지원 약속으로 해석하지 않는다.
- 목표의 기준 기기인 [iPhone 13](https://support.apple.com/en-ie/111872)은 TrueDepth 카메라를 탑재하지만 [Apple Intelligence 지원 기기](https://support.apple.com/en-gb/121115)에는 포함되지 않는다. 따라서 Apple 내장 LLM만으로 목표 기기의 AI 기능을 제공하는 방식은 이 목표를 충족하지 못한다.
- 별도 경량 일본어 LLM을 기기 내부에서 실행하는 안은 계속 검토한다. 제품 최종 모델 채택이나 서버 미사용을 확정한 것은 아니다.
- 14 Plus와 iPhone 13은 같은 A15 Bionic 이름을 사용하지만 GPU 구성이 다르다. 현재 보유 기기의 시험 결과만으로 iPhone 13의 지연 시간·메모리·발열과 전체 면접 흐름을 검증했다고 간주하지 않는다. 자세한 시험 환경과 미확인 항목은 [OPERATIONS.md](OPERATIONS.md)를 따른다.

### 6.7 첫 검증 LLM 선정 승인 (2026-11-05)
- 사용자는 LFM2.5-1.2B-JP-202606을 첫 검증 대상으로 선정하는 안을 명시적으로 승인했다.
- 일본어 면접 평가 품질, 응답 시간, 메모리 사용량, 발열을 확인한 뒤 제품 최종 채택 여부를 함께 결정한다. 수치로 된 합격 기준과 검증 자료는 미정이다.
- 이번 승인은 검증 모델 선정에 적용된다. 압축 형식, 실행 도구, 앱 구성, 최소 iOS 버전, 서버 사용 여부와 외부 전송 허용 여부는 확정하지 않았다.
- 모델 다운로드·설치, 검증 앱 구현, 실제 기기 시험은 아직 수행하지 않았다.

### 6.8 실행 도구 검토 (제안, 미승인)
모델을 앱에서 읽어 실행하는 도구는 별도로 선택해야 한다. 다음은 공식 자료에 근거한 후보이며 특정 도구를 채택한 상태가 아니다.

| 후보 | 확인한 근거 | 검증 전에 정할 사항 |
|---|---|---|
| [MLX Swift LM](https://github.com/ml-explore/mlx-swift-lm) | Swift로 모델 로딩·텍스트 생성 등을 구성하는 패키지이며 [LFM2 모델 구현](https://github.com/ml-explore/mlx-swift-lm/blob/main/Libraries/MLXLLM/Models/LFM2.swift)이 존재. 제작사의 [MLX 4비트 모델 파일](https://huggingface.co/LiquidAI/LFM2.5-1.2B-JP-202606-MLX-4bit)도 공개되어 있음 | 패키지 버전, 해당 모델 파일의 실제 로딩 호환성, 앱 구성, OS 조건과 메모리 사용량 |
| [llama.cpp](https://github.com/ggml-org/llama.cpp) | 제작사가 [GGUF 형식을 llama.cpp용으로 제공](https://huggingface.co/LiquidAI/LFM2.5-1.2B-JP-202606). CPU·Metal 등 실행 백엔드를 선택할 수 있음 | iOS 연동·빌드 구성, 버전, GGUF 압축 형식과 기기 성능 |

현재 제안은 Swift 패키지로 LFM 계열 구현을 활용할 수 있는 MLX Swift LM을 첫 검증용 실행 도구로 선택하는 것이다. 연동 구성의 편의를 고려한 제안이며, llama.cpp보다 빠르거나 적은 메모리를 사용한다는 측정 결과는 없다. 사용자 승인 후 선택을 기록하고, 검증 앱 구성과 최소 iOS 버전 등 나머지 사항을 논의한다.
