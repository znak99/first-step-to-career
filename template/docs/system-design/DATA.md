### 7.1 테스트용 데이터
<!-- 기능을 추가하거나 만들 때마다, 그 기능을 여러 기법으로 시험할 수 있는 데이터를 개발용 시드나 테스트 픽스처에 함께 추가한다. 완료 조건이다(TASK_GUIDE.md). -->
<!-- 아래 표의 "위치" 열에 그 데이터가 어느 파일에 있는지 적는다. -->
| 기법 | 넣어야 할 데이터 | 위치 |
|---|---|---|
| 경계값 | 최소값, 최대값, 그 바로 안팎 (예: 0, 1, 최대-1, 최대, 최대+1) | |
| 문자열 길이 | 빈 문자열, 최소 길이, 최대 길이, 최대 초과 | |
| 특수 문자 | 따옴표, 공백만, 앞뒤 공백, 줄바꿈, 이모지, 다국어(한글·일본어 등), HTML·SQL에서 의미 있는 기호(`< > ' " ; --`) | |
| 형식 | 잘못된 이메일·날짜·숫자·URL 형식 | |
| 수량 | 0건, 1건, 한 페이지를 넘는 다수, 중복 | |
| 상태 | 가능한 모든 상태값, 허용되지 않는 상태 전이 | |
| 동등 분할 | 유효한 값과 무효한 값의 대표 사례 각 하나 이상 | |
